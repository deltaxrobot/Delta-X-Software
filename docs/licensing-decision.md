# Licensing decision

Delta X Software first-party source and documentation are licensed under the
Apache License, Version 2.0 (`Apache-2.0`). The decision was adopted in August
2026 to support commercial/industrial integration and a stable plugin ecosystem
while retaining explicit contribution and patent terms.

The exact license is in the root `LICENSE`; required attribution is in `NOTICE`.
Contributions use Developer Certificate of Origin 1.1 sign-off as described in
`CONTRIBUTING.md`.

## Scope boundary

Apache-2.0 applies only where the project's copyright holders and contributors
have authority to license the material. It does not override third-party source,
vendor SDK, model, binary, trademark, or dataset terms. See
[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md) and
[`third-party-audit.md`](third-party-audit.md).

Historical Basler/Hikrobot SDK material and the YOLO model remain quarantined and
must be excluded from public release artifacts until provenance and redistribution
rights are verified. This is a release-composition restriction, not a change to
the first-party Apache-2.0 grant.
